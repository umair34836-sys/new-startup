04
TROUBLESHOOTING

Common issues and fixes.

Quick answers to the questions we hear most often.

Server won't start

Check console for errors, verify Java version, inspect server.properties, and review recent changes.

Read guide
Connection timeout / can't join

Verify IP and port, check firewall rules, confirm server is online in panel, test with local client.

Read guide
Lag / TPS drops

Check CPU/RAM usage, review plugins/mods, optimize Java flags, consider plan upgrade.

Read guide
Out of memory errors

Increase heap (-Xmx), reduce view distance, limit entities, or upgrade RAM.

Read guide
VPS: SSH connection refused

Check if server is running, verify SSH service, check firewall, use panel console as fallback.

Read guide
Panel not loading

Clear browser cache, try incognito, check for ad blockers, or use direct panel URL.

Read guide
