# Kinetic typography and motion graphics (HyperFrames / GSAP)

Scope: easing families, staggers, text splitting, typewriter/scramble, mask and clip reveals, SVG draw/morph/path motion, counters and charts, titles, logos and lower thirds, particles, parallax and CSS 3D — built with HyperFrames + GSAP (plus ffmpeg drawtext for quick text animation). Captions/subtitles (file 10) and After Effects (file 12) are out of scope.

Researched 2026-10-24 via agent-reach (Exa) web search, official docs and local tests. (Exa was rate-limited for most of the session; sources are gsap.com docs pages, MDN, the Flutter API pages that carry the Material 3 motion tokens, ffmpeg-filters.html — all fetched and read with curl — plus the HyperFrames skill references and the registry items installed here.)

How the "tested here" items were tested: GSAP behaviour was measured in a headless page (`chrome-headless-shell --no-sandbox --allow-file-access-from-files --dump-dom t.html`) that loaded the npm `gsap@3.14.2` core and plugins and printed each value (results in the session scratchpad `sk2_09/jt/results1.json`); a HyperFrames scene with SplitText, ScrambleText, DrawSVG, MorphSVG, MotionPath and a counter passed `npx hyperframes lint` and `check --json` and was snapshotted; every registry item named here was installed with `npx hyperframes add <name> --json` (HyperFrames 0.8.191, 178 installs, all ok) and its header comment read; ffmpeg lines were run on a `testsrc2` clip with ffmpeg 6.1.1 and DejaVuSans-Bold.


## Setup: GSAP plugins inside HyperFrames

2481. **Vendor GSAP plugins from the npm tarball** — every GSAP plugin (SplitText, ScrambleText, DrawSVG, MorphSVG, MotionPath, CustomEase, EasePack, Physics2D...) ships in the public `gsap` npm package next to the core, so the plugin build can match the vendored core exactly and never touch the CDN. **How:** `npm pack gsap@3.14.2 && tar xzf gsap-3.14.2.tgz` then copy `package/dist/SplitText.min.js` (etc.) into `assets/vendor/` beside `gsap-3.14.2.min.js` and load them with `<script src>` after the core (tested here 2026-10-24) [GSAP docs: Installation, https://gsap.com/docs/v3/Installation, checked 2026-10-24] [repo: CLAUDE.md "HyperFrames learnings"]
2482. **Register every plugin once before building the timeline** — plugins must be registered with `gsap.registerPlugin()`; registering twice does no harm. **How:** `gsap.registerPlugin(SplitText, DrawSVGPlugin, MorphSVGPlugin, MotionPathPlugin, ScrambleTextPlugin, CustomEase);` at the top of the scene script, then build `tl` and set `window.__timelines["main"]=tl` last; a 4 s test scene using all six passed `npx hyperframes check --json` with ok:true (tested here 2026-10-24) [GSAP docs: CustomEase, https://gsap.com/docs/v3/Eases/CustomEase, checked 2026-10-24] [repo: .claude/skills/hyperframes/references/runtimes.md]
2483. **EasePack is a separate file** — `slow`, `rough` and `expoScale` are not in the core; they live in EasePack, while CustomEase, CustomBounce and CustomWiggle are separate files too (CustomBounce/Wiggle also need CustomEase). **How:** copy `EasePack.min.js` (and `CustomEase.min.js` before `CustomBounce.min.js`/`CustomWiggle.min.js`) into `assets/vendor/`; `gsap.registerPlugin(EasePack, CustomEase, CustomBounce, CustomWiggle)` (tested here 2026-10-24) [GSAP docs: Easing, https://gsap.com/docs/v3/Eases, checked 2026-10-24] [GSAP docs: CustomBounce, https://gsap.com/docs/v3/Eases/CustomBounce, checked 2026-10-24] [repo: CLAUDE.md "HyperFrames learnings"]
2484. **Snapshot plugin scenes, don't trust the code** — SplitText masks, DrawSVG, MorphSVG, MotionPath and ScrambleText all rendered correctly in HyperFrames snapshots of a seeked paused timeline. **How:** `npx hyperframes snapshot --at 0.3,1.0,2.2,3.9` then open `.hyperframes/artifacts/snapshots/<id>/contact-sheet.jpg` and check each effect at mid-move and at rest (tested here 2026-10-24) [repo: .claude/skills/hyperframes/references/motion.md]
2485. **Prove seek-safety of a tween** — HyperFrames seeks frames out of order, so a tween must give the same value whichever way the playhead arrives; GSAP timelines did (seek 1.5 -> 0.25 -> 1.5 returned identical values). **How:** `tl.seek(1.5); a=o.x; tl.seek(0.25); tl.seek(1.5); console.assert(a===o.x)` in a headless page (tested here 2026-10-24) [repo: .claude/skills/hyperframes/references/runtimes.md]
2486. **Random-based plugins are not seed-stable** — ScrambleTextPlugin and the `rough` ease use `Math.random` (two RoughEase creations gave 0.321 vs 0.268 at the same progress), so each page load (preview, each render worker) can differ; HyperFrames wants seeded randomness. **How:** for frame-exact scrambles use the registry `scramble-reveal`/`matrix-decode` (fixed-seed tables) or set `rough({randomize:false})`; `grep -c Math.random dist/ScrambleTextPlugin.js` showed 3 uses (tested here 2026-10-24) [GSAP docs: ScrambleTextPlugin, https://gsap.com/docs/v3/Plugins/ScrambleTextPlugin, checked 2026-10-24] [GSAP docs: RoughEase, https://gsap.com/docs/v3/Eases/RoughEase, checked 2026-10-24] [repo: .claude/skills/hyperframes/references/runtimes.md]

## Easing families (GSAP core)

2487. **Default ease is power1.out** — a tween with no ease uses `power1.out`; at half time it is already 75% of the way. **How:** check with `gsap.parseEase('power1.out')(0.5)` -> 0.75; set your own default with `gsap.defaults({ease:'power2.out'})` or `gsap.timeline({defaults:{ease:'expo.out', duration:0.8}})` (tested here 2026-10-24) [GSAP docs: Easing, https://gsap.com/docs/v3/Eases, checked 2026-10-24]
2488. **Power ladder: pick strength by number** — power1..power4 (= quad, cubic, quart, quint) get steeper: at 50% time the .out versions read 0.75 / 0.875 / 0.938 / 0.969. **How:** `gsap.parseEase('power3.out')(0.5)` to compare (tested here 2026-10-24) [GSAP docs: Easing, https://gsap.com/docs/v3/Eases, checked 2026-10-24] [repo: .claude/skills/hyperframes/references/motion.md]
2489. **expo.out = almost there immediately** — expo.out reaches ~50% of the distance in the first 10% of the time and 97.7% at half time, the long tail HyperFrames recommends for arrivals. **How:** `tl.from(title,{y:60,opacity:0,duration:0.9,ease:'expo.out'},t)` (tested here 2026-10-24) [GSAP docs: Easing, https://gsap.com/docs/v3/Eases, checked 2026-10-24] [repo: .claude/skills/hyperframes/references/motion.md]
2490. **circ.out for a firm, round stop** — circ.out sits between power2 and power3 at mid-time (0.866). **How:** `ease:'circ.out'` when power2 is too soft and power3 too strong (tested here 2026-10-24) [GSAP docs: Easing, https://gsap.com/docs/v3/Eases, checked 2026-10-24]
2491. **sine.inOut for gentle drifts and loops** — sine.inOut is symmetric (exactly 0.5 at mid-time); HyperFrames eases camera moves both ways. **How:** `ease:'sine.inOut'` on a slow background drift (tested here 2026-10-24) [GSAP docs: Easing, https://gsap.com/docs/v3/Eases, checked 2026-10-24]
2492. **ease 'none' for constant motion** — `none` (linear) keeps speed constant: right for spins, tickers, progress bars and scrolling credits. **How:** `tl.to(strip,{xPercent:-50,duration:8,ease:'none'},0)` (tested here 2026-10-24) [GSAP docs: Easing, https://gsap.com/docs/v3/Eases, checked 2026-10-24] [repo: .claude/skills/hyperframes/references/motion.md]
2493. **back.out overshoot amount** — back.out(1.7) peaks 10% past the target; back.out(3) peaks 25% past. **How:** `ease:'back.out(1.4)'` on badges/pills; raise the number for more overshoot; never on opacity or colour (tested here 2026-10-24) [GSAP docs: Easing, https://gsap.com/docs/v3/Eases, checked 2026-10-24] [repo: .claude/skills/hyperframes/references/motion.md]
2494. **elastic.out amplitude and period** — elastic.out(amplitude, period): elastic.out(1,0.3) overshoots to 1.37, elastic.out(1,0.5) only to 1.20, so a larger period means a calmer spring. **How:** `ease:'elastic.out(1,0.5)'` for a premium spring, `elastic.out(1,0.3)` for a cartoon one (tested here 2026-10-24) [GSAP docs: Easing, https://gsap.com/docs/v3/Eases, checked 2026-10-24] [repo: .claude/skills/hyperframes/references/motion.md]
2495. **bounce.out never overshoots** — bounce.out bounces against the end value and never exceeds 1 (max 1.0 measured). **How:** `gsap.from(word,{y:-300,duration:1.2,ease:'bounce.out'})` for drop-in letters (tested here 2026-10-24) [GSAP docs: Easing, https://gsap.com/docs/v3/Eases, checked 2026-10-24]
2496. **steps(n) for frame-by-frame or digital looks** — `steps(5)` jumps in 5 equal increments (x to 100 gave 0,20,60,100 at progress .1,.3,.5,.99). **How:** `tl.to(caret,{opacity:0,duration:0.5,ease:'steps(1)',repeat:7,yoyo:true})` for a hard blink, or `steps(12)` for stop-motion (tested here 2026-10-24) [GSAP docs: SteppedEase, https://gsap.com/docs/v3/Eases/SteppedEase, checked 2026-10-24]
2497. **expoScale for zooms that look linear** — scale animated linearly appears to slow down; `expoScale(start,end)` bends the curve so the zoom feels even (scale 1->2 sits at 1.414 at half time instead of 1.5); start/end must be non-zero. **How:** `tl.fromTo(bg,{scale:1},{scale:2,duration:4,ease:'expoScale(1,2)'})`; add a third arg to bend another ease: `expoScale(0.5,3,power2.inOut)` (needs EasePack) (tested here 2026-10-24) [GSAP docs: ExpoScaleEase, https://gsap.com/docs/v3/Eases/ExpoScaleEase, checked 2026-10-24]
2498. **SlowMo: fly in, read, fly out in one tween** — `slow(linearRatio, power, yoyoMode)` decelerates, moves linearly, then accelerates; default 0.7/0.7, so 70% of the time is steady pace for reading. **How:** `tl.fromTo(line,{x:-900},{x:900,duration:4,ease:'slow(0.7,0.7)'})` (needs EasePack) (tested here 2026-10-24) [GSAP docs: SlowMo, https://gsap.com/docs/v3/Eases/SlowMo, checked 2026-10-24]
2499. **SlowMo yoyoMode for the matching fade** — with yoyoMode true the ease goes 0 -> 1 -> 0, so an opacity tween with the same duration fades in during the ease-in and out during the ease-out of the SlowMo move. **How:** `tl.from(line,{opacity:0,duration:4,ease:'slow(0.7,0.7,true)'},'<')`; measured values 0, .889, 1, .889, 0 at 0/.1/.5/.9/1 (tested here 2026-10-24) [GSAP docs: SlowMo, https://gsap.com/docs/v3/Eases/SlowMo, checked 2026-10-24]
2500. **RoughEase for jitter and glitch moves** — `rough({strength, points, template, taper, randomize, clamp})` wanders around a template ease; `clamp:true` keeps it inside start/end; `taper:'out'` calms it toward the end; it always ends on the target. **How:** `ease:'rough({strength:2,points:30,template:none.out,taper:out,randomize:false,clamp:true})'` (EasePack); randomize:false gives an even zig-zag that is the same every load (tested here 2026-10-24) [GSAP docs: RoughEase, https://gsap.com/docs/v3/Eases/RoughEase, checked 2026-10-24]
2501. **Ease the whole stagger, not just each item** — the stagger object has its own `ease` that spaces the start times; `'power2'` starts with big gaps that tighten (distribute with power2 gave 0, .578, .875, .984, 1). **How:** `stagger:{amount:0.6, ease:'power2'}` so the first items spread out and the last ones bunch up (tested here 2026-10-24) [GSAP docs: Staggers, https://gsap.com/docs/v3/Staggers, checked 2026-10-24] [GSAP docs: utils.distribute(), https://gsap.com/docs/v3/GSAP/UtilityMethods/distribute(), checked 2026-10-24]

## Custom eases (CustomEase, CustomBounce, CustomWiggle)

2502. **CustomEase from a cubic-bezier string** — CustomEase accepts the 4-number `cubic-bezier` format, so any curve from a design spec or cubic-bezier.com can drive GSAP. **How:** `CustomEase.create('m3emph', '.05,.7,.1,1'); tl.to(el,{y:0,ease:'m3emph'})` (tested here 2026-10-24) [GSAP docs: CustomEase, https://gsap.com/docs/v3/Eases/CustomEase, checked 2026-10-24]
2503. **CustomEase from SVG path data** — any SVG path built from M/C/S/L/Z commands becomes an ease (normalized internally); create it once and reference by name. **How:** `CustomEase.create('hop','M0,0 C0,0 0.056,0.442 0.175,0.442 0.294,0.442 0.332,0 0.332,0 0.332,0 0.414,1 0.671,1 0.991,1 1,0 1,0')` — returns to 0 at the end (measured 0.442, 0, 1, 0) (tested here 2026-10-24) [GSAP docs: CustomEase, https://gsap.com/docs/v3/Eases/CustomEase, checked 2026-10-24]
2504. **Draw the ease to check it** — `CustomEase.getSVGData(ease,{width,height,path})` returns/fills SVG path data of any ease, built-in or custom, for a visual check. **How:** `CustomEase.getSVGData('power2.out',{width:500,height:400,path:'#ease'})` (tested here 2026-10-24) [GSAP docs: CustomEase, https://gsap.com/docs/v3/Eases/CustomEase, checked 2026-10-24]
2505. **CustomBounce with synced squash** — CustomBounce.create(id,{strength, endAtStart, squash, squashID}) makes the bounce ease plus an `id-squash` ease for scaleX/scaleY that sticks at each impact. **How:** `CustomBounce.create('drop',{strength:0.7,squash:3}); tl.from(el,{y:-400,duration:2,ease:'drop'},0).to(el,{scaleX:1.3,scaleY:0.7,duration:2,ease:'drop-squash',transformOrigin:'50% 100%'},0)` (tested here 2026-10-24) [GSAP docs: CustomBounce, https://gsap.com/docs/v3/Eases/CustomBounce, checked 2026-10-24]
2506. **CustomBounce endAtStart for a hop** — with `endAtStart:true` the ease returns to the start value (measured 0 at the end): sit, leap, bounce back down to rest. **How:** `CustomBounce.create('hopb',{strength:0.6,endAtStart:true}); tl.to(logo,{y:-120,duration:1.4,ease:'hopb'})` (tested here 2026-10-24) [GSAP docs: CustomBounce, https://gsap.com/docs/v3/Eases/CustomBounce, checked 2026-10-24]
2507. **CustomWiggle for shakes that end at rest** — a wiggle ease goes to the value and back the same amount the other way, ending where it began (measured end 0, min -0.98); strength is the tween value, frequency is `wiggles`. **How:** `CustomWiggle.create('shake',{wiggles:8,type:'easeOut'}); tl.to(word,{rotation:8,duration:0.6,ease:'shake'})` (tested here 2026-10-24) [GSAP docs: CustomWiggle, https://gsap.com/docs/v3/Eases/CustomWiggle, checked 2026-10-24]

## Staggers and distribution

2512. **each vs amount** — `each` is the gap between starts (5 items, each 0.1, duration 1 -> total 1.4 s); `amount` is the total spread split among all items (amount 1 -> 2.0 s total regardless of count). **How:** use `stagger:{amount:0.5}` when the item count changes but the beat length must not (tested here 2026-10-24) [GSAP docs: Staggers, https://gsap.com/docs/v3/Staggers, checked 2026-10-24]
2513. **Negative stagger runs backwards** — a negative number makes the last element start first. **How:** `stagger:-0.06` for right-to-left letter reveals (tested here 2026-10-24) [GSAP docs: Staggers, https://gsap.com/docs/v3/Staggers, checked 2026-10-24]
2514. **Stagger from center or edges** — `from:'center'` starts in the middle and spreads out; `'edges'` starts at both ends and meets in the middle; also 'start','end','random' or an index. **How:** `stagger:{each:0.05, from:'center'}` for a title that blooms from its middle (tested here 2026-10-24) [GSAP docs: Staggers, https://gsap.com/docs/v3/Staggers, checked 2026-10-24]
2515. **Grid staggers** — with `grid:[rows,cols]` (or 'auto') the delay follows 2D distance from `from`; `axis:'x'|'y'` limits it to one axis; `from:[0.5,0.5]` is the centre, `[1,0]` the top-right corner. **How:** `stagger:{each:0.04, grid:[3,8], from:'center'}` on a tile/letter wall (tested here 2026-10-24) [GSAP docs: Staggers, https://gsap.com/docs/v3/Staggers, checked 2026-10-24]
2516. **Function stagger for custom rhythm** — a function `(index,target,list)` returns each item's total delay from the start (not from the previous one). **How:** `stagger:(i)=>i*i*0.04` for an accelerating cascade; 5 items with i*i*0.1 gave a 2.6 s tween (tested here 2026-10-24) [GSAP docs: Staggers, https://gsap.com/docs/v3/Staggers, checked 2026-10-24]
2517. **Repeat inside the stagger object** — repeat/yoyo/callbacks inside the stagger object apply per element; at top level they repeat the whole group after all finish. **How:** `stagger:{each:0.1, repeat:3, yoyo:true}`; in HyperFrames keep repeats finite: `repeat: Math.max(0, Math.floor(duration/cycle)-1)` [GSAP docs: Staggers, https://gsap.com/docs/v3/Staggers, checked 2026-10-24] [repo: .claude/skills/hyperframes/references/runtimes.md]
2518. **utils.distribute for any property** — distribute() is the engine behind advanced staggers and spreads any value by index/grid with base, amount/each, from, grid, axis and ease. **How:** `scale: gsap.utils.distribute({base:0.5, amount:0.5, from:'center'})` gave 1, .75, .5, .75, 1 across 5 items (edges big, centre small) (tested here 2026-10-24) [GSAP docs: utils.distribute(), https://gsap.com/docs/v3/GSAP/UtilityMethods/distribute(), checked 2026-10-24]
2519. **Stagger spacing by role** — letters about a frame apart, words 60-120 ms, list items 40-80 ms (registry stagger-cascade cites observed steps of 0.04-0.08 s, 0.14-0.18 s for deliberate item reveals). **How:** `stagger:1/30` for letters at 30 fps, `0.08` for words [repo: .claude/skills/hyperframes/references/motion.md] [repo registry: header comment of `compositions/components/stagger-cascade.html` installed by `npx hyperframes add stagger-cascade`, checked 2026-10-24]

## Timeline sequencing

2520. **Position parameter '<' and '>'** — `'<'` = start of the previous animation, `'>'` = its end; `'>0.5'` is half a second after it ends (measured starts 0, 0, 1.5). **How:** `tl.to(a,{...}).to(b,{...},'<').to(c,{...},'>0.5')` (tested here 2026-10-24) [GSAP: The Position Parameter, https://gsap.com/resources/position-parameter, checked 2026-10-24]
2521. **Percent offsets in the position parameter** — `'<25%'` = 25% into the previous animation; `'-=25%'` overlaps by 25% of the inserted animation's duration (measured 0, 0.5, 1.5). **How:** `tl.to(word2,{...},'<30%')` for 30%-done overlap between titles (tested here 2026-10-24) [GSAP: The Position Parameter, https://gsap.com/resources/position-parameter, checked 2026-10-24] [repo: .claude/skills/hyperframes/references/motion.md]
2522. **Labels as beat markers** — `addLabel('hit',2)` then `'hit+=0.5'` places tweens relative to a named moment. **How:** label each music hit: `tl.addLabel('drop', beatTimes[8])`; then `tl.from(title,{...},'drop')` (tested here 2026-10-24) [GSAP: The Position Parameter, https://gsap.com/resources/position-parameter, checked 2026-10-24]
2523. **Absolute times for HyperFrames** — HyperFrames places tweens at absolute seconds and wants start states in `fromTo`, not CSS. **How:** `tl.fromTo('#t',{opacity:0},{opacity:1,duration:0.4},2.4)` [repo: .claude/skills/hyperframes/references/runtimes.md]
2524. **Percentage keyframes** — keyframes `{'0%':{},'50%':{},'100%':{}}` inside one `to()`; default ease between keyframes is power1.inOut, change with `easeEach`, ease the whole block with `ease`. **How:** `tl.to(ball,{keyframes:{'0%':{y:0},'50%':{y:-200},'100%':{y:0}, easeEach:'sine.inOut'},duration:1})` (tested here 2026-10-24) [GSAP: Keyframes, https://gsap.com/resources/keyframes, checked 2026-10-24]
2525. **Array keyframes** — `keyframes:{x:[0,100,50]}` spreads values evenly over the duration; arrays need not have the same length. **How:** `keyframes:{x:[0,40,-20,0], y:[0,-30,0]}, duration:1.2` (tested here 2026-10-24) [GSAP: Keyframes, https://gsap.com/resources/keyframes, checked 2026-10-24]
2526. **Object keyframes with gaps** — an array of vars objects runs like chained to() tweens; `delay` creates gaps or overlaps (two 1 s steps with delay 0.5 -> 2.5 s). **How:** `keyframes:[{x:100,duration:1},{y:100,duration:1,delay:0.5}]` (tested here 2026-10-24) [GSAP: Keyframes, https://gsap.com/resources/keyframes, checked 2026-10-24]
2527. **from() renders immediately** — from()/fromTo() default to immediateRender:true, so a from() placed after a to() on the same property can jump at frame 0. **How:** prefer `fromTo` for every state that matters, or set `immediateRender:false` on the later from() [GSAP: Common GSAP mistakes, https://gsap.com/resources/mistakes, checked 2026-10-24]
2528. **Set initial transforms with GSAP too** — GSAP can't read units or rotation reliably back from computed matrices, so initial transforms should be set by GSAP. **How:** `gsap.set(el,{xPercent:-50,yPercent:-50,x:960,y:540})` before building tweens [GSAP: Common GSAP mistakes, https://gsap.com/resources/mistakes, checked 2026-10-24]
2529. **Combine xPercent with x** — xPercent/yPercent stack with pixel x/y, e.g. centre an element on a point. **How:** `gsap.set(dot,{xPercent:-50,yPercent:-50,x:300,y:200})` -> `translate(-50%,-50%) translate(300px,200px)` (tested here 2026-10-24) [GSAP docs: CSSPlugin, https://gsap.com/docs/v3/GSAP/CorePlugins/CSS, checked 2026-10-24] [GSAP: Common GSAP mistakes, https://gsap.com/resources/mistakes, checked 2026-10-24]
2530. **Finite yoyo length** — totalDuration includes repeats and repeatDelay: 1 s, repeat 3, yoyo, repeatDelay 0.2 -> 4.6 s. **How:** compute `repeat` from the clip length so the loop ends inside it (tested here 2026-10-24) [repo: .claude/skills/hyperframes/references/runtimes.md]
2531. **Reusable named effects** — `gsap.registerEffect({name, effect, defaults, extendTimeline:true})` turns a recipe into `tl.fadeUp(target,config,position)`. **How:** `gsap.registerEffect({name:'fadeUp',effect:(t,c)=>gsap.fromTo(t,{y:c.y,opacity:0},{y:0,opacity:1,duration:c.duration}),defaults:{y:40,duration:0.5},extendTimeline:true}); tl.fadeUp('#t',{y:20},0.3)` (tested here 2026-10-24) [GSAP docs: gsap.registerEffect(), https://gsap.com/docs/v3/GSAP/gsap.registerEffect(), checked 2026-10-24]

## Utilities, snapping and modifiers

## HyperFrames motion rules for type

2711. **Land titles dead still** — a landed title doesn't keep sliding or scaling; motion moves to the next element, the camera or the world. **How:** end every title tween with a plain hold; if a client says 'the titles move', remove drift [repo: .claude/skills/hyperframes/references/motion.md]
2712. **Vary title entrances within a film** — HyperFrames lists per-word blur-in, grey-to-ink per word, whole-line blur, per-letter for a name, title behind the subject and a slot-machine word roll — never fade+slide-up on every title. **How:** rotate entrances: blur-in for line 1, `kinetic-type-swap` for line 2, `per-word-rise` for line 3 [repo: .claude/skills/hyperframes/references/motion.md]
2713. **Hold time per line** — a line to be read holds about 0.5 s + 0.3 s per word; the film's last line at least 2 s; then exit with a 0.13-0.25 s blur-out/fade. **How:** for 6 words hold ~2.3 s before the exit tween [repo: .claude/skills/hyperframes/references/motion.md]
2714. **Exits shorter than entrances** — exits are 40-50% shorter than entrances; the next element starts when the previous is 30-50% done. **How:** entrance 0.6 s -> exit 0.3 s; next tween at `'<40%'` [repo: .claude/skills/hyperframes/references/motion.md] [GSAP: The Position Parameter, https://gsap.com/resources/position-parameter, checked 2026-10-24]
2715. **Client says 'too fast' or 'feels like slides'** — HyperFrames fixes: 'too fast' -> slow every zoom and pan to 0.7x of its speed, nothing else; 'feels like slides' -> enter the next scene through an object on screen and cut a move mid-flight. **How:** multiply only camera/zoom tween durations by 1/0.7; for slide-feel use `text-match-cut` or a zoom-through [repo: .claude/skills/hyperframes/references/motion.md]
2716. **Fit text to a width** — `window.__hyperframes.fitTextFontSize(text,{fontFamily,fontWeight,maxWidth})` returns a fontSize that fits. **How:** call it once in the build before splitting the text [repo: .claude/skills/hyperframes/references/runtimes.md]
2717. **Assert motion with a sidecar** — a `<name>.motion.json` makes `check` verify appearsBy, before, staysInFrame and keepsMoving on the seeked timeline. **How:** `{"assertions":[{"kind":"appearsBy","selector":"#headline","bySec":0.5}]}` then `npx hyperframes check --json` [repo: .claude/skills/hyperframes/references/motion.md]
2718. **Inspect a move's curve** — `npx hyperframes keyframes --json --selector '#id'` lists property, time, value, ease; `--shot motion.png` draws samples along the path. **How:** run it on a title after writing its tweens [repo: .claude/skills/hyperframes/references/motion.md]
2719. **Opt-in motion blur for fast type** — `data-motion-blur="on"` on the root smears fast 2D movers in preview and render (~1.7x render time); off with WebGL, backface flips or root opacity. **How:** add the attribute, then `npx hyperframes check` and look for `motion_blur_off` [repo: .claude/skills/hyperframes/references/motion.md]
2720. **Beat-grid timing for kinetic type** — frames per beat = fps*60/BPM; compute each beat from its index and round, never add a rounded beat repeatedly (drift). **How:** `const t=i=>Math.round(i*30*60/bpm)/30` for word hit times [repo: .claude/skills/hyperframes/references/motion.md]

## Missing tools

- **ffmpeg `drawvg` filter** (vector shapes drawn per frame with a script; documented on ffmpeg-filters.html, needs a build with `--enable-cairo`): our ffmpeg 6.1.1 has no drawvg (`ffmpeg -filters | grep drawvg` is empty). Free option: a newer FFmpeg release built with cairo (FFmpeg LGPL/GPL, https://ffmpeg.org/download.html). No skill above depends on it.
- **GSAP plugins are not missing** — they come from the free npm package (`npm pack gsap@3.14.2`), but they are not yet in `library/` or `video/assets/vendor/`; copy the needed `*.min.js` files from the tarball when a project uses them (npm package.json licence field: "Standard 'no charge' license: https://gsap.com/standard-license"; gsap.com says GSAP is now free for everyone).
- **Variable fonts** for the `wght`/`wdth` axis skills: `library/fonts/PlusJakartaSans-Variable.ttf` has a `wght` axis 200-800 (read with fontTools fvar, tested here 2026-10-24; licence `library/fonts/OFL-PlusJakartaSans.txt`). No `wdth`/`slnt` variable font is in `library/` yet.
