# NLE techniques translated to ffmpeg, HyperFrames and GSAP
Scope: classic Premiere Pro, DaVinci Resolve (Edit/Cut/Fusion) and Final Cut Pro timeline, trim, speed, effects-stack, keyframe, marker, nesting, multicam and media-management operations, each with how we do it here (no colour, audio-mix, caption or After Effects recipes).

Researched 2026-10-24 via official docs and local tests (pages fetched directly with curl; no agent-reach/Exa search was needed). Official sources read: Adobe Premiere desktop help pages (helpx.adobe.com/premiere/desktop/...), the DaVinci Resolve 19.1 Reference Manual PDF, the Final Cut Pro for Mac User Guide (support.apple.com), ffmpeg-filters/-formats/-codecs/ffmpeg.html, gsap.com docs, and the repo's HyperFrames skill files. Tests ran on synthetic 640x360 clips in the session scratchpad with ffmpeg 6.1.1, Node 22 + assets/vendor/gsap-3.14.2.min.js and hyperframes CLI 0.8.191. NLE facts are what the cited page says; the How lines are our translation, and '(tested here ...)' means that exact command or code ran and gave the stated result.


## Sequence, timeline and project settings

561. **Build the sequence from the main footage's properties** — Premiere performs best when the sequence settings match most of the assets (frame aspect, PAR, frame rate, fields, audio rate, codec); Final Cut Pro sets the whole project from the first video clip added, so add a clip that matches the delivery first. **How:** read the main clip first: `ffprobe -v error -select_streams v:0 -show_entries stream=width,height,r_frame_rate,sample_aspect_ratio -of csv=p=0 main.mp4`, then set the HyperFrames root `data-width`/`data-height` to the delivery size (new HyperFrames videos default to 1920x1080 at 30 fps). (tested here 2026-10-24) [Adobe Premiere help, https://helpx.adobe.com/premiere/desktop/edit-projects/change-clip-sequence/sequence-presets-and-settings.html, checked 2026-10-24] [Apple Final Cut Pro guide, https://support.apple.com/guide/final-cut-pro/conform-frame-sizes-and-rates-ver3363b44e/mac, checked 2026-10-24] [repo: .claude/skills/hyperframes/SKILL.md]
562. **Lock the project frame rate before editing** — Premiere locks the timebase once a sequence is created; Final Cut Pro warns that changing a project's frame rate can shift every edit point and cannot change it once the timeline has clips. **How:** decide fps first and keep one rate through the job; convert odd sources with the fps filter before editing, e.g. `ffmpeg -i H120.mp4 -vf fps=fps=25:round=down -an fd.mp4` (25 fps out). (tested here 2026-10-24) [Adobe Premiere help, https://helpx.adobe.com/premiere/desktop/edit-projects/change-clip-sequence/sequence-presets-and-settings.html, checked 2026-10-24] [Apple Final Cut Pro guide, https://support.apple.com/guide/final-cut-pro/conform-frame-sizes-and-rates-ver3363b44e/mac, checked 2026-10-24] [Apple Final Cut Pro guide, https://support.apple.com/guide/final-cut-pro/final-cut-pro-project-settings-ver1b946a4ff/mac, checked 2026-10-24] [ffmpeg docs, https://ffmpeg.org/ffmpeg-filters.html#fps-1, checked 2026-10-24]
563. **Timebase by delivery region** — Premiere's guidance: 24 for motion-picture film, 25 for PAL/SECAM video, 29.97 for NTSC video; a 23.976 preset needs the Custom editing mode. **How:** the ffmpeg fps filter has named rates for these: `fps=film` (24), `fps=pal` (25), `fps=ntsc` (30000/1001), `fps=ntsc_film` (24000/1001). [Adobe Premiere help, https://helpx.adobe.com/premiere/desktop/edit-projects/change-clip-sequence/sequence-settings-reference.html, checked 2026-10-24] [Adobe Premiere help, https://helpx.adobe.com/premiere/desktop/edit-projects/change-clip-sequence/create-a-custom-sequence-preset.html, checked 2026-10-24] [ffmpeg docs, https://ffmpeg.org/ffmpeg-filters.html#fps-1, checked 2026-10-24]
564. **Drop-frame timecode for 29.97 material** — Premiere: with NTSC assets use 30-fps drop-frame timecode so the displayed duration is accurate. **How:** burn a drop-frame counter with drawtext's timecode option (the doc gives the format hh:mm:ss[:;.]ff): `ffmpeg -i A.mp4 -vf "fps=30000/1001,drawtext=timecode='00\:00\:00;00':rate=30000/1001:fontcolor=white:fontsize=28:x=20:y=20" -an -frames:v 5 tcd.mp4`. (tested here 2026-10-24) [Adobe Premiere help, https://helpx.adobe.com/premiere/desktop/edit-projects/change-clip-sequence/sequence-settings-reference.html, checked 2026-10-24] [ffmpeg docs, https://ffmpeg.org/ffmpeg-filters.html#drawtext-1, checked 2026-10-24]
565. **Give the program a start timecode** — Resolve's new-timeline dialog defaults the start timecode to 01:00:00:00, and Final Cut Pro projects and compound clips have a Starting Timecode field. **How:** stamp it on the delivered file: `ffmpeg -i A.mp4 -c copy -timecode 01:00:00:00 tc.mov`, then check with `ffprobe -v error -show_entries stream_tags=timecode -of csv=p=0 tc.mov` (prints 01:00:00:00). (tested here 2026-10-24) [Blackmagic, DaVinci Resolve 19.1 Reference Manual ch.28 "Fast Editing in the Cut Page", https://documents.blackmagicdesign.com/UserManuals/DaVinci_Resolve_19_Reference_Manual.pdf, checked 2026-10-24] [Apple Final Cut Pro guide, https://support.apple.com/guide/final-cut-pro/create-a-new-project-verdb79783e/mac, checked 2026-10-24] [ffmpeg docs, https://ffmpeg.org/ffmpeg.html#Main-options, checked 2026-10-24]
566. **Don't shrink the frame size to get smoother playback** — Premiere: don't change the sequence frame size to compensate for slow playback; change the playback quality instead and set the final size at export. **How:** keep the root `data-width`/`data-height` at delivery size and preview with `npx hyperframes render --quality draft` (or Studio preview) instead of editing the canvas size. [Adobe Premiere help, https://helpx.adobe.com/premiere/desktop/edit-projects/change-clip-sequence/sequence-settings-reference.html, checked 2026-10-24] [repo: .claude/skills/hyperframes-cli/SKILL.md]
567. **Use timeline proxy resolution for heavy previews** — Resolve's Timeline Proxy Resolution plays a 1920x1080 timeline at 960x540 (Half) or 480x270 (Quarter) without changing the project, separate from proxy media files. **How:** for a quick look at an ffmpeg composite, render a half-size review copy: `ffmpeg -i in.mp4 -vf scale=iw/2:-2 review.mp4`; the delivery render stays full size. [Blackmagic, DaVinci Resolve 19.1 Reference Manual ch.8 "Improving Performance, Proxies, and the Render Cache", https://documents.blackmagicdesign.com/UserManuals/DaVinci_Resolve_19_Reference_Manual.pdf, checked 2026-10-24] [ffmpeg docs, https://ffmpeg.org/ffmpeg-filters.html#scale-1, checked 2026-10-24]
568. **Convert anamorphic pixels to square before compositing** — Premiere's PAR table: 720x480 is D1/DV NTSC 0.91 (4:3) or 1.21 (16:9), 720x576 PAL 1.09/1.46, 1440x1080 HDV 1.33; images look distorted when non-square pixels are shown on square-pixel screens. **How:** check `sample_aspect_ratio` and resample to square pixels: `ffmpeg -i SD.mp4 -vf "scale=iw*sar:ih,setsar=1" -frames:v 1 sq.png` turned an 8:9 720x480 clip into 640x480 at 1:1. (tested here 2026-10-24) [Adobe Premiere help, https://helpx.adobe.com/premiere/desktop/edit-projects/intro-to-editing/aspect-ratios.html, checked 2026-10-24] [Adobe Premiere help, https://helpx.adobe.com/premiere/desktop/edit-projects/intro-to-editing/pixel-aspect-ratio.html, checked 2026-10-24] [ffmpeg docs, https://ffmpeg.org/ffmpeg-filters.html#setdar_002c-setsar, checked 2026-10-24]
569. **Override a wrongly flagged pixel aspect** — Premiere's Interpret Footage lets you 'Conform To' a different PAR when a file's flag is wrong, and says to fix PAR before frame aspect, because a wrong PAR causes a wrong frame aspect. **How:** re-flag without resampling: `ffmpeg -i SD.mp4 -vf setsar=1 -an -c:v libx264 par1.mp4` (ffprobe then reports 1:1). setsar only changes the flag; setdar/setsar doc: DAR = W/H x SAR. (tested here 2026-10-24) [Adobe Premiere help, https://helpx.adobe.com/premiere/desktop/edit-projects/intro-to-editing/correct-aspect-ratio-misinterpretations.html, checked 2026-10-24] [Adobe Premiere help, https://helpx.adobe.com/premiere/desktop/edit-projects/intro-to-editing/aspect-ratios.html, checked 2026-10-24] [ffmpeg docs, https://ffmpeg.org/ffmpeg-filters.html#setdar_002c-setsar, checked 2026-10-24]
570. **Swap field order instead of guessing** — Premiere's Interpret Footage offers No Fields (progressive), Upper Field First or Lower Field First; check camera docs or metadata before changing, and preview the result. **How:** ffmpeg's fieldorder shifts the picture a line to convert tff/bff and does nothing to frames not flagged interlaced; tested chain: `ffmpeg -i A.mp4 -vf "tinterlace=mode=interleave_top,setfield=tff,fieldorder=bff" -an -frames:v 10 fo.mp4`. (tested here 2026-10-24) [Adobe Premiere help, https://helpx.adobe.com/premiere/desktop/edit-projects/modify-clip-properties/change-the-field-order-of-a-clip.html, checked 2026-10-24] [ffmpeg docs, https://ffmpeg.org/ffmpeg-filters.html#fieldorder, checked 2026-10-24] [ffmpeg docs, https://ffmpeg.org/ffmpeg-filters.html#setfield-1, checked 2026-10-24]
571. **Four spatial-conform choices for mismatched frame sizes** — Final Cut Pro offers Fit (default, no crop, bars), Fill (crop the long side) and None (native size, cropped or surrounded by black); Resolve adds Stretch; Premiere's Properties panel has Fit to frame / Fill frame. **How:** Fit `scale=1280:720:force_original_aspect_ratio=decrease,pad=1280:720:-1:-1`; Fill `scale=1280:720:force_original_aspect_ratio=increase,crop=1280:720`; None `pad=1280:720:-1:-1`; Stretch `scale=1280:720,setsar=1` (all four gave 1280x720 from a 720x480 clip). (tested here 2026-10-24) [Apple Final Cut Pro guide, https://support.apple.com/guide/final-cut-pro/conform-frame-sizes-and-rates-ver3363b44e/mac, checked 2026-10-24] [Blackmagic, DaVinci Resolve 19.1 Reference Manual ch.50 "Compositing and Transforms in the Timeline", https://documents.blackmagicdesign.com/UserManuals/DaVinci_Resolve_19_Reference_Manual.pdf, checked 2026-10-24] [Adobe Premiere help, https://helpx.adobe.com/premiere/desktop/edit-projects/intro-to-editing/edit-video-using-the-properties-panel.html, checked 2026-10-24] [ffmpeg docs, https://ffmpeg.org/ffmpeg-filters.html#scale-1, checked 2026-10-24] [ffmpeg docs, https://ffmpeg.org/ffmpeg-filters.html#pad-1, checked 2026-10-24]
572. **Treat high-frame-rate clips as slow motion on purpose** — Final Cut Pro's Automatic Speed plays every frame of a 120 fps clip at the 30 fps project rate, so the action takes longer with no skipped or duplicated frames. **How:** `ffmpeg -i H120.mp4 -vf "setpts=4*PTS,fps=30" -an hfr.mp4`: a 1 s, 120-frame clip became 4 s with all 120 frames. (tested here 2026-10-24) [Apple Final Cut Pro guide, https://support.apple.com/guide/final-cut-pro/change-clip-speed-ver40b00150/mac, checked 2026-10-24] [ffmpeg docs, https://ffmpeg.org/ffmpeg-filters.html#setpts_002c-asetpts, checked 2026-10-24]
573. **Reinterpret a clip's frame rate (duration changes too)** — Premiere's 'Assume this frame rate' changes the whole clip, audio included; a 10 s 24 fps clip set to 48 fps becomes 5 s. **How:** rescale input timestamps with `-itsscale`: `ffmpeg -itsscale 2 -i A.mp4 -c:v libx264 -an its.mp4` turned a 3 s clip into ~6 s. For one instance only, use setpts on that clip instead. (tested here 2026-10-24) [Adobe Premiere help, https://helpx.adobe.com/premiere/desktop/edit-projects/modify-clip-properties/change-the-frame-rate-of-a-clip.html, checked 2026-10-24] [ffmpeg docs, https://ffmpeg.org/ffmpeg.html#Advanced-options, checked 2026-10-24]
574. **Choose floor or nearest when conforming frame rate** — Final Cut Pro's Rate Conform offers Fast (Floor) (duplicates or rounds down, default) and Fast (Nearest Frame) (rounds up or down; fewer artifacts but may stutter), then frame blending and optical flow. **How:** the fps filter exposes the same rounding choice: `fps=fps=25:round=down` vs `fps=fps=25:round=near` (default is near). (tested here 2026-10-24) [Apple Final Cut Pro guide, https://support.apple.com/guide/final-cut-pro/conform-frame-sizes-and-rates-ver3363b44e/mac, checked 2026-10-24] [ffmpeg docs, https://ffmpeg.org/ffmpeg-filters.html#fps-1, checked 2026-10-24]

## Putting clips into the timeline (edit types)

575. **Insert edit = split, add, ripple** — An insert edit pushes everything after the edit point later; inserted in the middle of a clip, Final Cut Pro cuts that clip and moves its second half after the new clip (Premiere: comma key; FCP: W; Resolve F9). **How:** ffmpeg: trim the host clip into two and concat with the new clip between: `[0:v]trim=0:1.5,setpts=PTS-STARTPTS[a1];...[1:v]trim=0:1,...[b];[0:v]trim=1.5:3,...[a2];[a1][x1][b][y][a2][x2]concat=n=3:v=1:a=1` (3 s + 1 s = 120 frames). (tested here 2026-10-24) [Apple Final Cut Pro guide, https://support.apple.com/guide/final-cut-pro/insert-clips-ver4e2eff6/mac, checked 2026-10-24] [Adobe Premiere help, https://helpx.adobe.com/premiere/desktop/edit-projects/intro-to-editing/add-media-to-the-timeline-using-source-patching.html, checked 2026-10-24] [ffmpeg docs, https://ffmpeg.org/ffmpeg-filters.html#concat, checked 2026-10-24] [ffmpeg docs, https://ffmpeg.org/ffmpeg-filters.html#trim, checked 2026-10-24]
576. **Overwrite edit keeps the program length** — Overwrite replaces frames for the incoming clip's duration and ripples nothing; in Final Cut Pro it works on a range, not clip boundaries (D; Premiere period key; Resolve F10). **How:** keep A 0-1 s, B 1 s, A 2-3 s: `[0:v]trim=0:1,setpts=PTS-STARTPTS[a1];[1:v]trim=0:1,setpts=PTS-STARTPTS[b];[0:v]trim=2:3,setpts=PTS-STARTPTS[a2];[a1][b][a2]concat=n=3:v=1:a=0` with the original audio mapped (90 frames out, same as in). (tested here 2026-10-24) [Apple Final Cut Pro guide, https://support.apple.com/guide/final-cut-pro/overwrite-clips-ver4e30026/mac, checked 2026-10-24] [Blackmagic, DaVinci Resolve 19.1 Reference Manual ch.28 "Fast Editing in the Cut Page", https://documents.blackmagicdesign.com/UserManuals/DaVinci_Resolve_19_Reference_Manual.pdf, checked 2026-10-24] [ffmpeg docs, https://ffmpeg.org/ffmpeg-filters.html#concat, checked 2026-10-24]
577. **Append = start after the previous clip** — Append (FCP E, Resolve Append to End Shift-F12) always puts the clip after the last clip, ignoring the playhead. **How:** in HyperFrames write `data-start="clipA + 0"` so the clip starts when clipA ends; `npx hyperframes timeline --json` resolved it to 3 s after a 3 s clipA. A typo silently resolves to 0, so snapshot it. (tested here 2026-10-24) [Apple Final Cut Pro guide, https://support.apple.com/guide/final-cut-pro/append-clips-to-your-project-ver7a77f584/mac, checked 2026-10-24] [Blackmagic, DaVinci Resolve 19.1 Reference Manual ch.39 "Three- and Four-Point Editing", https://documents.blackmagicdesign.com/UserManuals/DaVinci_Resolve_19_Reference_Manual.pdf, checked 2026-10-24] [repo: .claude/skills/hyperframes/references/format.md]
578. **Connect / place on top for B-roll and titles** — FCP connect (Q) attaches a clip above the primary storyline; Resolve's Place on Top always uses the first empty track above (video) or below (audio) and creates tracks; upper tracks cover lower ones except where alpha is transparent. **How:** HyperFrames paints by `z-index` (track index is only a lane), so give the overlay the highest z-index; in ffmpeg: `[1:v]scale=320:-2,setpts=PTS-STARTPTS+1/TB[pip];[0:v][pip]overlay=x=W-w-20:y=20:enable='between(t,1,2)':eof_action=pass`. (tested here 2026-10-24) [Apple Final Cut Pro guide, https://support.apple.com/guide/final-cut-pro/connect-clips-ver7a77ef9e/mac, checked 2026-10-24] [Blackmagic, DaVinci Resolve 19.1 Reference Manual ch.39 "Three- and Four-Point Editing", https://documents.blackmagicdesign.com/UserManuals/DaVinci_Resolve_19_Reference_Manual.pdf, checked 2026-10-24] [Adobe Premiere help, https://helpx.adobe.com/premiere/desktop/add-video-effects/work-with-composites/compositing-overview.html, checked 2026-10-24] [repo: .claude/skills/hyperframes/references/format.md] [ffmpeg docs, https://ffmpeg.org/ffmpeg-filters.html#overlay-1, checked 2026-10-24]
579. **Backtimed edit (align the out point)** — Final Cut Pro's backtimed three-point edit (Shift-D overwrite, Shift-Q connect) lines the source end up with the timeline mark, e.g. to end exactly on a beat; Resolve's Close Up/Place On Top/Overwrite also backtime when only a timeline Out is set. **How:** start = out - duration; for a 1 s clip ending at 2.5 s: `[1:v]trim=0:1,setpts=PTS-STARTPTS+(2.5-1)/TB[b];[0:v][b]overlay=enable='between(t,1.5,2.5)':eof_action=pass`. (tested here 2026-10-24) [Apple Final Cut Pro guide, https://support.apple.com/guide/final-cut-pro/three-point-edit-examples-ver549f253e/mac, checked 2026-10-24] [Blackmagic, DaVinci Resolve 19.1 Reference Manual ch.28 "Fast Editing in the Cut Page", https://documents.blackmagicdesign.com/UserManuals/DaVinci_Resolve_19_Reference_Manual.pdf, checked 2026-10-24] [ffmpeg docs, https://ffmpeg.org/ffmpeg-filters.html#overlay-1, checked 2026-10-24]
580. **Three-point rule: which marks win** — With source In+Out and a timeline In, the source marks set the duration; with source In and timeline In+Out, the timeline range sets it; source In+Out with only a timeline Out backtimes; FCP needs range selections for most three-point edits. **How:** write the rule into the edit list: duration = (timeline out - timeline in) if both are set, else (source out - source in); start = timeline in, or timeline out - duration when only an out is given. [Apple Final Cut Pro guide, https://support.apple.com/guide/final-cut-pro/three-point-editing-guidelines-verf44671a73/mac, checked 2026-10-24] [Apple Final Cut Pro guide, https://support.apple.com/guide/final-cut-pro/intro-to-three-point-editing-ver549f2208/mac, checked 2026-10-24] [Blackmagic, DaVinci Resolve 19.1 Reference Manual ch.39 "Three- and Four-Point Editing", https://documents.blackmagicdesign.com/UserManuals/DaVinci_Resolve_19_Reference_Manual.pdf, checked 2026-10-24]
581. **Fit to Fill (four-point edit retimes the clip)** — Fit to Fill uses all four marks and changes speed so a source range fills a timeline range; Resolve: it doesn't ripple; Premiere's Rate Stretch tool does the same by dragging; FCP has 'Replace with Retime to Fit'. **How:** speed factor = target/source: `ffmpeg -i A.mp4 -vf "setpts=PTS*(2/3)" -an -r 30 -t 2 ftf2.mp4` fit 3 s into exactly 60 frames (without `-t` it came out 62 frames). 582. **Replace from Start / Replace from End** — FCP replace options: Replace (source length, ripples), Replace from Start (source from its first frame, target length), Replace from End (source end aligned, target length); replace works on whole clips. **How:** from start: `ffmpeg -i B.mp4 -t 1.2 -an rfs.mp4`; from end: `ffmpeg -sseof -1.2 -i B.mp4 -an rfe.mp4` (both 36 frames for a 1.2 s slot). 583. **Replace edit aligned on a matching frame** — Resolve's Replace (F11) uses the timeline clip's duration and lines up the frame under the Source playhead with the frame under the Timeline playhead, e.g. swapping a VFX version over the camera original. **How:** pick the source frame S that must sit at timeline time T inside a clip starting at C: new media start = S - (T - C); in HyperFrames set that as `data-media-start` and keep `data-start`/`data-duration`. 584. **Ripple Overwrite swaps a clip and fixes the length** — Resolve's Ripple Overwrite substitutes the clip at the playhead (or an In/Out range) with a clip of a different length and ripples later clips to fill or make room. **How:** in HyperFrames change the clip's src/duration, then move every later clip by the length difference (GSAP-style `shiftChildren`, or `npx hyperframes timeline apply plan.json` with one move per clip, moving the last clip first). 585. **Video-only and audio-only edits** — FCP Edit menu Video Only (Shift-2) / Audio Only (Shift-3) / All (Shift-1); Resolve Cut page has Audio Only and Video Only toggles. **How:** take one side of a source: `ffmpeg -i A.mp4 -an -c copy vo.mp4` (video stream only) and `ffmpeg -i A.mp4 -vn -c copy ao.m4a` (audio only). 586. **Close Up edit from a wide shot** — Resolve's Close Up edit adds the incoming clip at about 150% scale and repositions any detected face; meant for 4K-in-1080 or 8K-in-4K timelines so the punch-in loses no quality. **How:** a 150% punch-in is a crop of 1/1.5 of the frame scaled back: `crop=iw/1.5:ih/1.5,scale=1920:1080` (or tween `scale: 1.5` on a wrapper in HyperFrames); face finding needs a detector (see Missing tools). 587. **Source overwrite for synced cameras** — Resolve's Source Overwrite (and 'Insert Selected Clips to Timeline Using Timecode') places a cutaway from another camera at the matching timecode, so it lands in sync automatically. **How:** with a known camera offset O (B started O s after A), the B frames for timeline range t1-t2 are B time t1-O to t2-O: `[1:v]trim=t1-O:t2-O,setpts=PTS-STARTPTS+t1/TB` then overlay with `enable='between(t,t1,t2)'`. (tested here 2026-10-24) [Adobe Premiere help, https://helpx.adobe.com/premiere/desktop/add-video-effects/apply-video-transitions/clip-handles-settings.html, checked 2026-10-24] [Adobe Premiere help, https://helpx.adobe.com/premiere/desktop/add-video-effects/apply-video-transitions/transitions-overview.html, checked 2026-10-24] [ffmpeg docs, https://ffmpeg.org/ffmpeg-filters.html#tpad, checked 2026-10-24]
617. **xfade overlaps the clips (the timeline gets shorter)** — FCP: a transition without media handles can overlap the two clips instead, which is effectively a ripple edit and shortens the project. **How:** ffmpeg xfade always overlaps by `duration`: two 3 s clips with `xfade=transition=fade:duration=1:offset=2` give 5 s, not 6 s; pad both clips first if the length must stay. (tested here 2026-10-24) [Apple Final Cut Pro guide, https://support.apple.com/guide/final-cut-pro/how-transitions-are-created-ver761c7150/mac, checked 2026-10-24] [ffmpeg docs, https://ffmpeg.org/ffmpeg-filters.html#xfade, checked 2026-10-24]
618. **Centre, start or end the transition on the cut** — Premiere's alignment: Center at Cut (both ends move), Start at Cut (only the end moves), End at Cut (only the start moves); FCP keeps the centre fixed when you change the duration. **How:** xfade's offset is measured on the first input; for a planned cut at C with duration D: centre = C - D/2 (D/2 of handle each side), start at cut = C (outgoing needs D after C), end at cut = C - D (incoming needs D before its In). Tested centre: both clips padded 0.5 s with `tpad=...:clone`, then `xfade=transition=fade:duration=1:offset=2.5` -> 6 s total. (tested here 2026-10-24) [Adobe Premiere help, https://helpx.adobe.com/premiere/desktop/add-video-effects/apply-video-transitions/align-transitions.html, checked 2026-10-24] [Apple Final Cut Pro guide, https://support.apple.com/guide/final-cut-pro/adjust-transitions-in-the-timeline-vercf3c662c/mac, checked 2026-10-24] [ffmpeg docs, https://ffmpeg.org/ffmpeg-filters.html#xfade, checked 2026-10-24]
619. **Single-sided transition when one side has no handle** — Premiere applies a single-sided transition to one clip only (End at Cut / Start at Cut, or automatically when the clip has no neighbour), e.g. one shot leaving with a wipe and the next fading in. **How:** fade only the incoming clip: `ffmpeg -i A.mp4 -vf fade=in:0:30 -an fin.mp4` (first 30 frames), or `fade=t=out:st=2:d=1` on the outgoing clip. 620. **One default transition everywhere, then change by exception** — Premiere's defaults are Cross Dissolve and Constant Power crossfade at 1 s; 'Apply Default Transitions to Selection' fills every edit where two selected clips touch; FCP's default duration is a setting; replacing a transition keeps its alignment and duration but resets its settings. **How:** generate the xfade chain from a list in Python (offset_i = running length - D) with one default name/duration, and override per edit; swapping `transition=` keeps offset/duration unchanged. ## Speed and time effects

625. **Speed change with or without ripple** — FCP Custom Speed has a Ripple checkbox: off, a slowed clip keeps its length and shows less of the action (a sped-up one leaves a gap); Premiere Speed/Duration has 'Ripple Edit, shift trailing clips'; Resolve has 'Ripple Sequence'. **How:** no ripple: slow and cut to the old length, `ffmpeg -i A.mp4 -vf "setpts=2*PTS" -an -t 3 snr.mp4` (89 frames, half the action); ripple: let it run 6 s and move later clips. HyperFrames: `data-playback-rate` with the duration you want. ## Keyframes and interpolation in GSAP terms

654. **Linear keyframes = ease 'none'** — Premiere Linear interpolation is an even rate of change that starts and stops abruptly; FCP's Linear curve keeps a constant rate. **How:** GSAP's default ease is power1.out, so write `ease: "none"` for linear; tested: value 2.5 at 25% of a 0->10 tween. ## More timeline translations

711. **Smart Insert: snap to the nearest existing cut** — Resolve's Cut-page Smart Insert puts the incoming clip at the edit point nearest the playhead (shown by the Smart Indicator) and won't insert at an arbitrary frame; Place On Top also snaps to an edit within five frames. **How:** keep a list of edit times and snap the wanted time to it: `gsap.utils.snap([0,3,5,8], 4.2)` -> 5, `snap([0,3,5,8], 6.9)` -> 8; then insert there. (tested here 2026-10-24) [Blackmagic, DaVinci Resolve 19.1 Reference Manual ch.28 "Fast Editing in the Cut Page", https://documents.blackmagicdesign.com/UserManuals/DaVinci_Resolve_19_Reference_Manual.pdf, checked 2026-10-24] [ffmpeg docs, https://ffmpeg.org/ffmpeg-filters.html#tpad, checked 2026-10-24] [ffmpeg docs, https://ffmpeg.org/ffmpeg-filters.html#apad, checked 2026-10-24]
