## Things worth knowing (found by the audit)

- `loudnorm` in dynamic mode upsamples to 192 kHz (ffmpeg docs: "the audio stream will be upsampled to 192 kHz. Use the
  -ar option"); measured 192000 Hz to WAV and 96 kHz into AAC. from-scratch.md now adds `-ar 48000`.
- `.claude/skills/client-brand-kit` told to run `python3 setup-specialist-d.sh` (a bash script: SyntaxError). Fixed to `bash`.
- skills/05 #433: `overlay,despill` after the key despilled the whole picture (a green bar in the background went
  0,254,0 -> 0,0,0); despill now runs on the keyed layer before overlay.
- skills/05 #398: `fontfile=DejaVuSans-Bold.ttf` without a path silently drew regular DejaVu Sans; full path given.
- skills/03 #206: `waveform` default `mirror=1` puts high values at the top (`ffmpeg -h filter=waveform`: default true).
- Reddit (www/old/api) returned 403 from this container through every route on 2026-10-24, so Reddit-only claims are
  marked "(unverified)" with their links kept for a later check. agent-reach (jina/Exa) rate-limited the helpers for
  ~45 min mid-audit; they used WebSearch/WebFetch/curl instead.
